#  From Zero to AI Agent Builder

A hands-on learning journey to build intelligent AI Agents using **AWS Bedrock, Amazon Nova Pro, Strands SDK, Ollama, Memory Systems, MCP (Model Context Protocol), Tool Calling, and Streaming Responses**.

This repository contains five progressive challenges designed to take learners from creating a simple chatbot to developing advanced AI agents capable of using tools, remembering context, retrieving knowledge, and interacting with external systems.

---

### Challenge 1 – Your First AI Agent
Build a basic conversational AI agent using Strands SDK and Ollama.

**Key Features**
- Local LLM integration
- Interactive chatbot
- Prompt-based conversations
- Agent fundamentals

**Technologies**
- Python
- Strands SDK
- Ollama
- Llama 3.2

---

### Challenge 2 – Adding Tools to Your Agent
Enhance your AI agent with tool-calling capabilities.

**Included Tools**
- Calculator
- Weather Assistant
- Age Calculator

**Key Features**
- Automatic tool selection
- Function calling
- Task-specific responses

**Technologies**
- Python
- Strands SDK
- Ollama

---

### Challenge 3 – Agent with Persistent Memory
Create an AI agent that remembers information across conversations.

**Key Features**
- User preference storage
- Conversation history
- Context-aware responses
- Personalized interactions

**Technologies**
- AWS Bedrock
- Amazon Nova Pro
- Strands SDK
- Memory Storage Layer

---

### Challenge 4 – Full AI Agent
Combine memory, tools, and streaming responses into a production-style AI assistant.

**Key Features**
- Persistent memory
- Tool calling
- Streaming responses
- Context management
- Multi-step reasoning

**Workflow**

User Query → Memory Retrieval → Tool Execution → Streaming Response → Memory Update

**Technologies**
- AWS Bedrock
- Amazon Nova Pro
- Strands SDK

---
